# ZoneRank Victoria — Next.js

Look up the government school zone for any Victorian (Australia) street address, then cross-check the assigned primary school against Better Education's *Top Public Primary Schools in Melbourne* index — with per-user saved searches, notes, and starred comparisons when signed in.

Migrated from the Vite + tRPC app in the repository root (legacy code in `../api`, `../src`, `../contracts` — kept for reference).

## Stack

- **Next.js 16** (App Router, TypeScript) — frontend + API route handlers
- **Plain CSS design system** (ported verbatim from the Vite app; Tailwind v3 present for the shadcn-style base layer)
- **better-auth** — Google OAuth sign-in
- **Drizzle ORM + Postgres (Supabase)** — auth tables, `search_history`, and the cached `better_education_rankings` row
- **cheerio + zod** — Better Education table parsing + input validation
- **dotenvx** — encrypted env files; secrets never appear in the repo as plaintext

All external data fetches happen server-side only (Mapshare Vic geocoder, Find My School, Better Education). The browser never calls them directly.

## Quick start

Requires [Bun](https://bun.sh) (developed on 1.3.x; Vercel auto-detects it from `bun.lock`).

```bash
bun install
bun run dev        # http://localhost:3000
```

Environment variables are loaded from the **encrypted `.env`** that is committed to this repo. To decrypt it you need `.env.keys`, which is **never committed** — copy it to this directory once (ask the project owner, or regenerate values with `bunx dotenvx set`, see below). Keep a backup of `.env.keys`; losing it means the committed secrets are unrecoverable.

### Setting / rotating secrets

Never edit `.env` by hand. Use dotenvx so values are encrypted before they touch disk:

```bash
bunx dotenvx set DATABASE_URL "postgresql://..." -f .env --encrypt
bunx dotenvx set GOOGLE_CLIENT_ID "....apps.googleusercontent.com" -f .env --encrypt
bunx dotenvx set GOOGLE_CLIENT_SECRET "GOCSPX-..." -f .env --encrypt
bunx dotenvx set BETTER_AUTH_SECRET "$(openssl rand -base64 32)" -f .env --encrypt
```

### Required variables

| Variable | What |
| --- | --- |
| `BETTER_AUTH_SECRET` | Session-signing secret. Already generated and committed (encrypted). Rotate with the command above. |
| `BETTER_AUTH_URL` | App base URL — `http://localhost:3000` in dev, your domain in production. |
| `DATABASE_URL` | Postgres connection string (Supabase → Project Settings → Database). |
| `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` | Google Cloud Console → APIs & Services → Credentials → OAuth 2.0 Client ID (Web application). |

Google OAuth authorized redirect URIs must include:

- `http://localhost:3000/api/auth/callback/google` (development)
- `https://<your-production-domain>/api/auth/callback/google` (production)

Without Google credentials the app still runs — sign-in is simply unavailable and lookups work anonymously. Without `DATABASE_URL`, auth and saved searches degrade gracefully while anonymous lookups keep working.

### Database schema

The initial migration is generated SQL in `drizzle/` (generated by `drizzle-kit generate`). Apply it once:

```bash
psql "$DATABASE_URL" -f drizzle/0000_*.sql
```

(Or paste the file into the Supabase SQL editor.) After changing `drizzle/schema.ts`, regenerate with `bun run db:generate`.

### Refreshing the ranking cache

`bun run db:refresh-rankings` scrapes the Better Education table (via `curl` — bun/node `fetch` is TLS-fingerprinted and rejected) and upserts the `primary-melbourne` row. It must run from a non-blocked (residential) IP. When Better Education publishes a new year's table, the script stores the new `ranking_year` automatically and the staleness warning clears itself.

## Deploying (Vercel)

1. Push the repository and import it in Vercel with **root directory `next-app`**.
2. Set the env vars in Project → Settings → Environment Variables. Environment variables set on the platform take precedence over the committed encrypted `.env`, so this is the recommended approach for production (production `BETTER_AUTH_URL` = your domain, plus `DATABASE_URL` and the Google credentials).
   - **Vercel serverless is IPv4-only**: the direct Supabase host (`db.<ref>.supabase.co`) is IPv6-only and will fail with `ENOTFOUND`. Use the Supavisor pooler — `postgresql://<role>.<project-ref>:<password>@aws-0-<region>.pooler.supabase.com:6543/postgres?sslmode=no-verify` — the `<role>.<project-ref>` username is required because serverless TLS may not send SNI.
3. Add the production Google OAuth redirect URI.
4. Deploy. `bun run build` must pass; there is no other build step.

## How lookups work

1. **Address autocomplete** — Mapshare Vic ArcGIS geocoder `/suggest` (live, debounced, keyboard-navigable).
2. **Zone lookup** — Find My School `lookup/{year}/{primary|year7}/{lng},{lat}` plus `schools-{year}.json` metadata, for enrolment years 2026/2027.
3. **Ranking cross-check** — Better Education table parsed with Cheerio. Better Education blocks datacenter IPs (Cloudflare), so production servers cannot scrape it live; the source chain is direct scrape → Supabase cache (`better_education_rankings` row, shown as "Cached from database") → bundled snapshot (`src/data/betterEducationPrimaryFallback.ts`, always warned about). Every ranking carries a `rankingYear`; when it is older than the current calendar year the API adds a staleness warning, and saved history snapshots keep the year, source, and warnings from the moment of the search. Schools are matched by normalised name with postcode tie-breaking; absence from the index is reported explicitly, and secondary zones show "primary ranking not applicable".

Caching is in-memory per server instance (ranking 6 h, school metadata 6 h).

## Auth & saved searches

Sign in with Google (better-auth). Signed-in lookups are saved automatically (best-effort — a failed save never breaks a lookup). `/history` shows a comparison table: star preferred searches, attach notes, bulk-delete, and expand any row to see the full zone + ranking detail again. History is per-user and stored as immutable JSONB snapshots.

## Verified examples

- `31 North Avenue, Bentleigh VIC 3204` → Bentleigh West Primary School — Better Education rank **#22** of 232 (2025 index).
- `5 Victoria Street, Footscray VIC 3011` → Footscray Primary School — correctly reported as **not listed** in the index.
